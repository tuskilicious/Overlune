# AGENTS.md: Overlune

Instructions for coding agents (Codex and others). Claude Code reads `CLAUDE.md`; this file points every other agent at the same rules.

1. **Follow `CLAUDE.md` exactly.** It holds the project's rules: security, secrets, overlay link contract, accessibility, workflow. If a request conflicts with it, say so before doing anything.
2. **Read `docs/HANDOFF.md` first.** It covers where the work stands, the owner's preferences, open PRs, what's next and the known gotchas.
3. Then read the doc each task needs:
   - `docs/PRD.md`: product.
   - `docs/TASKS.md`: the plan; work one task at a time.
   - `docs/STACK.md`: stack, folders and link format.
   - `docs/DESIGN.md`: looks and UI rules, including the overlay playbook.
   - `docs/ASSETS.md`: asset licenses.
   - `docs/OBS-TESTING.md`: OBS test steps.
